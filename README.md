# 요나고 여행 플래너 — 날짜별 공유 핀

이 폴더를 Git 저장소의 루트에 올린 뒤 Vercel에 연결합니다. `index.html`, `cover.webp`, `leaflet.js`, `leaflet.css`, `api/pins.js`, `package.json`을 함께 유지하세요.

## Vercel 설정

1. Vercel에서 이 저장소를 새 프로젝트로 가져옵니다. Framework Preset은 **Other**, Root Directory는 이 폴더를 올린 위치로 둡니다.
2. 프로젝트의 **Storage**에서 **Blob** 저장소를 만들고 접근을 **Private**로 선택합니다. 프로젝트 환경에 `BLOB_READ_WRITE_TOKEN`이 연결되어야 합니다.
3. 배포 후 사이트의 날짜별 일정에서 지도를 누르고 핀을 저장합니다.
4. **공유 링크 복사**로 얻은 주소를 다른 기기에서 엽니다. 그 링크를 가진 사람은 모든 날짜의 핀을 추가하고 삭제할 수 있습니다. 여행 링크의 `#trip=` 값은 편집 권한이므로 공개 게시를 피하세요.

핀은 Vercel Blob에 저장됩니다. 다른 기기에서 변경 사항을 보려면 **핀 새로고침**을 누르거나 페이지를 새로고침하세요. 지도 배경에는 인터넷 연결이 필요합니다. 로컬 `file://` 미리보기는 기존처럼 브라우저에만 핀을 저장하며, 그 핀은 배포된 사이트로 자동 이동하지 않습니다.
